# Read-04 — Solo Cuidadores

## Objetivo
Evidenciar la lectura de cuidadores (nombre y turno).

## Métodos del código referenciados
- App._mostrar_listas()

## Pasos para reproducir
1) Ejecutar el programa.
2) Elegir la opción **1) Listar datos**.

## Salida de consola (solo la sección 'Cuidadores')
== Cuidadores ==
 1) Ana (turno Mañana)
 2) Bruno (turno Tarde)

## Notas
Los cuidadores se cargan en `_cargar_datos_ejemplo()` y se listan en `_mostrar_listas()`.
