# Read-10 — Lectura de interacción: Limpiar hábitat

## Objetivo
Evidenciar el impreso de limpieza de hábitat por parte del cuidador.

## Métodos del código referenciados
- App._pedir_animal()
- App._primer_cuidador()
- Cuidador.limpiarHabitat()

## Pasos para reproducir
1) Ejecutar el programa.
2) Elegir **9) Limpiar hábitat (cuidador)**.
3) Introducir un ID válido (ej. **A4**).

## Salida de consola (ejemplo)
ID del animal (ej. A1): A4
[Cuidador Ana] Limpiando hábitat 'Costa fría'… ¡Limpio!

## Notas
Se usa el primer cuidador disponible (`Ana`) mediante `_primer_cuidador()`.  
No se modifica la lógica; solo se documenta la lectura impresa por el sistema.
